# Database

The dataset used in this project is the German Traffic Sign Recognition Benchmark (GTSRB) dataset from Kaggle.

Due to the large size of the dataset, the database files are not included directly in this repository.

You can download the original dataset from the following link:

[German Traffic Sign Recognition Benchmark Dataset](https://www.kaggle.com/datasets/meowmeowmeowmeowmeow/gtsrb-german-traffic-sign)

## Dataset Information

The GTSRB dataset contains images of German traffic signs and is designed for traffic sign recognition and image classification tasks.

The dataset contains multiple classes representing different types of traffic signs.

Please download the dataset from Kaggle and place the required files in the appropriate project directory before running the project.

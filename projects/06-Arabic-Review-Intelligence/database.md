
# Database

The dataset used in this project is the Arabic 100K Reviews dataset from Kaggle.

Due to the large size of the dataset, the database files are not included directly in this repository.

You can download the original dataset from the following link:

[Arabic 100K Reviews Dataset](https://www.kaggle.com/datasets/abedkhooli/arabic-100k-reviews)

## Dataset Information

The dataset contains 100,000 Arabic-language reviews and can be used for Natural Language Processing and sentiment analysis tasks.

Please download the dataset from Kaggle and place the required files in the appropriate project directory before running the project.

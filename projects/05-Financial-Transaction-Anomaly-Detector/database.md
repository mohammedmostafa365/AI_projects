
# Database

The dataset used in this project is the Credit Card Fraud Detection dataset from Kaggle.

Due to the large size of the dataset, the database files are not included directly in this repository.

You can download the original dataset from the following link:

[Credit Card Fraud Detection Dataset](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)

## Dataset Information

The dataset contains credit card transactions and is designed for fraud detection tasks.

The target variable is `Class`:

* `0` represents a legitimate transaction.
* `1` represents a fraudulent transaction.

The dataset is highly imbalanced, with fraudulent transactions representing a small portion of the total transactions.

Please download the dataset from Kaggle and place the required files in the appropriate project directory before running the project.
